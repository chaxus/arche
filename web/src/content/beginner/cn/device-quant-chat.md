## 要点

### 1. 为什么要这三块

只有算子不够跑聊天：设备、体积、消息格式都要。

### 2. 覆盖什么

1. **设备** — CUDA → MPS → CPU  
2. **INT8（教学）** — 权重更小；简单反量化  
3. **对话模板** — 角色 → 模型要的字符串（HF 或纯文本回退；可试 demo）

### 3. 版图

| 主题 | 生产备注 |
| --- | --- |
| 量化 | INT8/INT4/FP8… 配方很多 |
| 模板 | 模型相关；别随便发明 |
| 设备 | 同一图，不同后端 |

### 4–6. 本课怎么做

教学辅助 + 脚本——不是完整量化产品。
