## 要点

预训练之后，还要会**跟对话**、**更偏好好回答**。

- **SFT**（监督微调）：用「提示→回答」样本训练，但**掩掉提示**，损失只打在回复 token 上。  
- **DPO**（直接偏好优化）：给定更好 / 更差回答，相对**冻结的 reference** 把模型推向更好那一侧——基础形式不需要单独奖励模型。我们只跑**教学用的一步**。

```bash
python chapters/02-training/ep19_sft_dpo.py
```
